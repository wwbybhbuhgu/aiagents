# AI Agents 操作指南

本指南是 AI Agents 应用的官方使用说明。当用户询问应用功能、设置方法或操作步骤时，参考本指南回答。

> **重要原则**：本指南中的"手动设置"部分必须引导用户自己在 App 内操作，**AI 不得调用工具擅自修改**这些配置。

---

## 一、工作区（Workspace）

### 1.1 什么是工作区
工作区是 AI 的 Linux 沙盒环境，提供独立的文件系统（`/workspace`）、命令执行（终端）和 Rootfs（Linux 系统环境）。AI 的所有文件操作、命令执行、代码运行都在工作区内进行，不会影响设备本身。

### 1.2 首次启动
- 首次启动时，如果没有就绪的工作区，App 会自动进入引导页，自动创建默认工作区并下载 Rootfs（Linux 环境）。
- Rootfs 下载需要几分钟，请保持网络连接，不要中途退出。
- 下载完成后自动进入聊天页。

### 1.3 手动设置：绑定工作区到助手
每个助手（Assistant）必须绑定一个工作区才能使用文件/命令能力：
1. 进入**助手设置**页面
2. 找到**工作区**选项
3. 选择一个已就绪的工作区（当前设计为强制绑定，无法选择"不绑定"）
4. 若没有可用工作区，先在**工作区管理**页创建并等待安装完成

### 1.4 工作区目录结构（容器内视角）
- `/workspace`：工作区文件区（AI 的主要工作目录，可读写）
- `/upload`：上传目录，用户上传的文件都会出现在这里（可读写，所有工作区共享）
- `/skills`：技能目录，AI 使用技能时从 `/skills/<技能名>/SKILL.md` 读取
- `/sd`：共享目录，位于设备存储 `AI-Agent/sd`（用户可见）
- `/screenshots`：截图目录，对应设备 `AI-Agent/screenshots`
- `/memories`：记忆目录，对应设备 `AI-Agent/memories`
- `/tool_outputs`：工具输出目录

### 1.5 手动设置：工作区文件管理器
在**工作区详情**页可以浏览文件：
- 点击目录进入，点击文件查看内容
- 根目录下可以看到 `upload`、`sd` 等挂载目录
- 文本文件可直接在**文件编辑器**中查看/编辑

### 1.6 手动设置：工作区终端
在**工作区详情**页可打开终端，直接输入 Linux 命令。终端与 AI 共享同一个 Rootfs，AI 的操作在终端中可见。

## 二、聊天与消息

### 2.1 发送消息
- 输入文字后点击发送按钮（右下角）
- 仅上传文件（无文字）也可发送：上传文件或图片后，发送按钮会启用

### 2.2 编辑消息
- 长按自己的消息可以编辑
- 编辑后会重新发送，AI 基于修改后的内容重新回答

### 2.3 上传文件
- **图片按钮**：可上传任意格式文件（不限于图片），文件保存到工作区 `/upload`
- **文件按钮**：可上传任意类型文件，同样保存到 `/upload`
- 上传后 AI 会收到文件路径，自行调用工具读取分析（不会自动 OCR/提取内容）
- 粘贴长文本时，可在设置中选择"长文本自动保存为文件"（超过阈值时）

### 2.4 语音输入
- 输入框旁有**麦克风按钮**，点击可语音输入（需在**设置 → 语音**中配置语音识别 ASR 服务）
- 语音识别后文字自动填入输入框

### 2.5 快捷消息
- 输入框左侧的**快捷消息按钮**可快速插入预设的快捷消息（在**扩展 → 快捷消息**中管理）
- 快捷消息可绑定到具体助手

### 2.6 手动设置：搜索
- 联网搜索默认启用，AI 会自行选择合适的搜索引擎
- 想添加/更换搜索引擎：进入**设置 → 搜索**，添加或管理搜索服务
- 想更换默认搜索引擎：在搜索服务列表中**长按服务并上下拖动排序**，排到第一位即为默认引擎
- 搜索引擎需要 API Key 的（如 Tavily、Exa），请在搜索服务设置中自行填入（**AI 不应代替用户填写 API Key**）

### 2.7 手动设置：功能开关
- 输入框上方有**联网搜索**、**手机自动化**、**浏览器自动化**等开关，可随时开启/关闭对应能力
- 手机自动化、浏览器自动化需先在**设置 → 自动化**中完成权限配置

## 三、模型与提供商

### 3.1 手动设置：添加模型
1. 进入**设置 → 提供商**
2. 添加提供商（如 OpenAI、Gemini、自定义 API）
3. 添加模型，选择模型 ID、输入/输出模态、能力
4. API Key 等敏感信息请在提供商设置中**手动填写**（AI 不应代替用户配置密钥）

### 3.2 手动设置：默认模型
- 在**设置 → 模型**中配置默认聊天模型、图片生成模型等
- 图片生成模型选项只显示生图（IMAGE）类型的模型

### 3.3 图片分析（OCR）
- AI 分析图片时，自动使用设置中配置的 OCR/视觉模型
- 图片过大时会自动压缩后分析
- 本地优先使用 OpenCV（`cv_image`）做网格/模板/颜色/轮廓/OCR，云端视觉模型只做兜底

## 四、助手（Assistant）

### 4.1 什么是助手
- 助手是 AI 的"人格/配置"载体，每个助手可绑定不同的工作区、模型、提示词、记忆、技能等
- 在**助手**页面可创建、编辑、切换多个助手

### 4.2 手动设置：助手详情
进入助手详情页可配置：
- **基础**：名称、头像、绑定工作区、默认模型
- **提示词**：系统提示词（System Prompt）
- **记忆**：长期记忆条目（AI 可主动写入）
- **请求**：请求参数（温度、最大 token 等）
- **MCP**：为该助手启用的 MCP 服务器
- **本地工具**：启用的本地工具（手机自动化、浏览器自动化等）
- **注入**：提示词注入（见"扩展"章节）
- **扩展**：为该助手启用的技能

---

## 五、委派 Agent

### 5.1 什么是委派 Agent
AI 可以把复杂任务委派给子 Agent 在后台运行，子 Agent 完成后结果返回给主模型，主模型会总结后回复用户。

### 5.2 委派结果展示
- 委派结果以**可折叠卡片**显示在聊天中（点击展开查看完整结果）
- 主模型会基于委派结果重新总结，最终回答是总结后的内容

## 六、图片生成

### 6.1 使用
- 告诉 AI"生成一张图片"，AI 会调用图片生成工具
- 生成的图片**保存到工作区 `/workspace/images/`**，AI 可通过工具查看
- 用户可到工作区文件管理器查看生成的图片

## 七、扩展（Extensions）

扩展入口在**设置 → 扩展**，包含：

### 7.1 快捷消息
- 预设常用消息，聊天时一键插入（见"聊天与消息"章节）

### 7.2 提示词（Prompts）
包含三类：
- **模式注入（Mode Injection）**：按模式注入的提示词，可设置注入位置（系统提示前/后、对话顶部/底部、指定深度）、优先级、角色
- **Lorebook（世界书）**：按关键词/正则触发的提示词条目，命中时自动注入
- **正则注入（Regex Injection）**：Lorebook 中的条目，支持正则匹配

### 7.3 技能（Skills）
- 技能是给 AI 的指令包，每个技能是一个目录，含 `SKILL.md`（含 `name`、`description` 元数据）
- 在**技能**页面可导入（从文件/压缩包/GitHub）、创建、编辑、删除技能
- 技能可绑定到具体助手（在助手详情 → 扩展中启用）
- 技能目录位于设备 `AI-Agent/skills`，容器内挂载到 `/skills`
- 系统内置技能（如本指南 `ai-agents-user-guide`）始终对模型可用，不显示开关

### 7.4 工作区
- 工作区管理入口（创建、删除、查看详情）

## 八、手机自动化

### 8.1 手动设置：开启
1. 进入**设置 → 自动化**
2. 开启**无障碍服务**（AI 可读取屏幕并执行点击/滑动/输入）
3. 可选开启 **Shizuku**（用于需要 root/shell 权限的操作，如 `auto_shell`）
4. 在聊天输入框开启**手机自动化**开关

### 8.2 能力
开启后 AI 可以：
- 读取屏幕内容/界面状态（无障碍树）
- 截图并做像素级分析（本地 OpenCV）
- 代替用户操作屏幕：点击、滑动、输入、滚动、返回、回桌面、回车
- 打开/结束应用、安装 APK、设置壁纸
- 发短信、拨打电话、查联系人、获取位置
- 调音量、调亮度、媒体控制
- 开关 Wi-Fi、手电筒、通知栏
- 打开链接/深链接、震动
- 使用内置 AI 键盘向其他应用输入文字

## 九、浏览器自动化

### 9.1 手动设置：开启
- 在聊天输入框开启**浏览器自动化**开关
- 使用内置 AI 浏览器（区别于系统浏览器）

### 9.2 能力
开启后 AI 可以：
- 打开网页（内置浏览器）
- 获取页面元素结构、点击、输入、填表、滚动、执行 JS
- 截图查看页面

## 十、MCP

### 10.1 手动设置：添加 MCP 服务器
1. 进入**设置 → MCP**
2. 添加 MCP 服务器（配置地址、认证等）
3. 在助手详情 → MCP 中为具体助手启用

### 10.2 说明
- MCP 服务器为 AI 提供额外的工具能力
- 连接与工具同步成功后，AI 才能使用该服务器的工具

---

## 十一、Web 服务器

### 11.1 手动设置：开启
- 进入**设置 → Web 服务器**，开启本地 Web 服务
- 可配置端口、访问方式等

### 11.2 说明
- 开启后可通过浏览器访问 App 提供的 Web 界面/API

---

## 十二、定时任务

### 12.1 手动设置：管理
- 进入**设置 → 定时任务**，可查看/管理 AI 创建的定时任务与提醒
- AI 可通过 `reminder_create`（到点提醒/闹钟）和 `cron_create`（定时/周期任务）创建

### 12.2 说明
- 定时任务在 App 内调度执行，进程被杀/重启后会自动重排

---

## 十三、语音（Speech）

### 13.1 手动设置：配置
- 进入**设置 → 语音**，配置：
  - **语音合成 TTS**：AI 朗读文本（`text_to_speech`）
  - **语音识别 ASR**：语音输入转文字（聊天输入框麦克风）
- 内置本地 TTS/ASR 模型（打包在 APK 中，无需额外配置），也可添加在线服务

### 13.2 说明
- 朗读文本时 AI 会提供干净、自然、适合听觉的文本

---

## 十四、备份

### 14.1 手动设置：备份与恢复
- 进入**设置 → 数据 → 备份**，可备份/恢复聊天记录、设置、技能等数据
- 支持本地备份与云同步（S3/WebDAV）

### 14.2 聊天存储
- 在**设置 → 数据 → 聊天存储**可查看聊天文件占用并清理

---

## 十五、记忆（Memories）

### 15.1 说明
- 助手可维护**长期记忆**（在助手详情 → 记忆中管理）
- AI 会主动把值得跨对话记住的信息写入记忆（`memory_tool`）
- 记忆目录位于设备 `AI-Agent/memories`，容器内挂载到 `/memories`

## 十六、常见问题

### 16.1 为什么上传的图片在容器里看不到？
- 上传文件在 `/upload` 目录（所有工作区共享）
- 在工作区文件管理器或终端 `ls /upload` 查看

### 16.2 为什么 AI 说图片"过大无法分析"？
- 新版已支持自动压缩，若仍失败可能是图片异常，可让 AI 用 `image_analysis` 重新分析

### 16.3 为什么我不能选择"不绑定工作区"？
- 工作区是 AI 的沙盒基础，为保证安全，现在强制每个助手必须绑定工作区

### 16.4 终端 `ls /` 看不到 upload/sd 目录？
- 需要先打开工作区终端（会启动容器），挂载目录在容器启动后可见

### 16.5 手机自动化点了没反应？
- 检查**设置 → 自动化**中无障碍服务是否已开启并连接
- 检查聊天输入框的**手机自动化**开关是否开启

### 16.6 语音输入/朗读没声音？
- 检查**设置 → 语音**中是否已配置 TTS/ASR 服务
- 检查系统麦克风/媒体音量权限

### 16.7 敏感设置（AI 不得擅自修改）
以下设置必须由用户手动完成，AI 只能指导操作，**不得调用工具修改**：
- API Key、Token 等密钥信息
- 搜索服务的密钥配置
- 默认引擎的排序（长按拖动）
- 系统级权限（无障碍、存储、通知等）

## 十七、给 AI 的提示

当用户询问操作指南相关内容时：
1. 先阅读本指南对应章节
2. 指导用户逐步操作（说明"在哪里点、怎么设置"）
3. 涉及敏感配置时，明确告诉用户"请在设置中手动完成"
4. **不要代替用户调用工具修改设置**（尤其是密钥、API Key、默认引擎排序、系统权限）
